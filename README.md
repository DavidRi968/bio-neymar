LinkBio Neymar Jr

Este é um projeto de página de links (Linktree) personalizado com foco no jogador Neymar Jr. O objetivo principal foi consolidar conhecimentos em estruturação semântica, manipulação de tabelas de dados e estilização com vídeos de fundo.

Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página (tags `video`, `table`, `thead`, `tbody`).
- **CSS3**: Estilização visual, layouts com Flexbox, efeitos de transição (`:hover`) e gerenciamento de camadas (`z-index`).
- **Google Fonts**: Integração das fontes *Ysabeau Infant* e *Montserrat*.

Funcionalidades

- Vídeo de fundo em loop com preenchimento responsivo (`object-fit: cover`).
- Árvore de links interativa para as principais redes sociais do jogador.
- Tabela de estatísticas estilizada com cores alternadas nas linhas (`nth-of-type`).
- Efeito visual de gradiente personalizado e selo de verificado no perfil.
